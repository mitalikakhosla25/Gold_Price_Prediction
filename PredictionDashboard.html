Project Phases Summary

Phase 1 — Data Cleaning

  • Handled missing values using Median Imputation
  • Removed duplicate rows
  • Detected + capped outliers using IQR
  • Created Market_Trend categorical feature
  • Date → Year, Month, Day extraction

Phase 2 — EDA

  • Statistical Summary
  • Distribution Analysis
  • Correlation Heatmap
  • Multicollinearity using VIF
  • Target relationship analysis

Phase 3 — Feature Selection

  • Full Features for Tree Models
  • Reduced Features for Linear Regression
  • Removed high VIF features
  • 80:20 Train-Test Split
  • Shuffle optimization for better performance

Phase 4 — Model Training

  • Linear Regression
  • Decision Tree Regressor
  • Random Forest Regressor
  • XGBoost Regressor
  • MAE, MSE, RMSE, R² Comparison
